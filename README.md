# Ana, o céu aprendeu seu nome

Site romântico e interativo feito para Gustavo e Ana.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste ZIP diretamente para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Selecione **main** e **/(root)**, depois clique em **Save**.

O site funciona sem instalação e sem servidor próprio.
